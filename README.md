## 1. Project analysis, User profile

The main persona that will be interested in looking through this CV website is an HR looking for a recent-graduate in Computer Engineering, that will also look at the CV-website design as part of the decision making.

## 2. Project analysis, Information architecture.

The information that a CV contains is primarly contact information, prefessional experiences, selected projects, tecnical skill list, languages and  education. 

At the start of the page, in the header, I have put my name and degree name, as the main identifier of the website.

The next element is the Professional Experience section, that is listed in chronological order, most recent experience first for the sake of convenience for the reader. Each item includes the role next to the company name, then the period of time during which I worked there, and a relevant listing of achivements in that position. This section has the next priority to the heading, because it gives the reader a general view of the practical experience, and demostrates the obtained results in previous real-world situations.

Next to the experience section, we have the Highlighted projects. It includes the name of the project and a short description of what was made, technologies and skills used. This serves as an extra block of information, contibuting to the professional experience and expanding it.

Next, a three column row that contains the education in the first column, tecnical skills in the second, and languages spoken in the third column to be brief in this block of information.

At the end of the page, I have placed the links to my contacts as icons. This makes it for the visitor of my website to have easy acces to the contact information, some of them are links, some are copied to the user's clipboard on click.

I have used flexbox design to separate some elements instead of using tables, for example to separate the period of work for the Professional experience section, and to separate the three columns of Education, Technical Skills and Languages.

## 3. Project analysis, Visual design

As my main inspiration, I had used the minimalistic CV design, with no face picture to avoid extra distraction. It has a simple 3 color scheme and a sans-serif font. 

The layout is balanced and clean, I have intentionally avoided using any extra graphical elements (like borders, frames, section separation lines or any other sort of decorative elements) to not distract or visually overwhelm the reader and reflect the practical personality of the CV.

The primary color is white; it is used for the main text. The dark blue is used for the background to contrast with the contents and a modern-tech look, that reflects calmness. A lighter shade of blue is used for the segments to visually separate the different main sections of the CV.

For easier visual navigation and to avoid any extra decoration, I have chosen a bigger font size and a different color for sections, and a smaller font size for the content in each section. The selected sans-serif font is used because of its modern appearance and in order to improve readability.

Overall, the visual design follors the natural reading flow, making it efficient to find the relevant information, aims to express clarity simplicity and efficiency.
